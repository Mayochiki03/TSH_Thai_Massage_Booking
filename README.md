# ระบบจองคิวนวดแผนไทย (Thai Massage Booking)

เว็บแอปจองคิวรับบริการนวดแผนไทยของโรงพยาบาล (หมอนวด 1 คน) เปิดใช้งานผ่าน **LINE OA** ของโรงพยาบาล
ผู้ป่วยจองคิวได้เองจากมือถือ ได้ **e-ticket พร้อมรหัสจอง 6 หลัก** ไว้แสดงที่เคาน์เตอร์ เจ้าหน้าที่เช็กอินด้วยรหัสจอง และหมอนวดบันทึกผลการรักษาได้ในระบบเดียว

> สถานะ: **กำลังพัฒนา (v0.2.0)** — ฝั่งผู้จอง, เคาน์เตอร์ และหมอนวด ใช้งานได้ในโหมดทดสอบแล้ว · หน้าแอดมินและการเชื่อม LINE จริงอยู่ระหว่างพัฒนา (ดู [CHANGELOG](CHANGELOG.md))

---

## ความสามารถ

**ผู้จอง (มือถือ ผ่าน LINE)**
- จองคิวได้ล่วงหน้า 1–2 วัน วันละ 6 รอบ เห็นรอบว่างแบบเรียลไทม์
- จองให้ตัวเองหรือคนอื่นได้ (เช่น ลูกจองให้แม่) ระบบบันทึกว่า "ใครจอง ให้ใคร"
- รองรับทั้งผู้ป่วยที่มี HN และบุคคลทั่วไป
- e-ticket รหัสจอง 6 หลัก (ไม่ต้องใช้ QR / เครื่องสแกน) ส่งเข้าแชท LINE อัตโนมัติ
- ยืนยัน / ยกเลิกคิวเองได้ถึง 2 ชั่วโมงก่อนนัด
- แจ้งเตือนก่อนนัด 2 ชั่วโมง พร้อมปุ่ม "ยืนยัน" / "ยกเลิก"

**เจ้าหน้าที่เคาน์เตอร์**
- คิวรายวันแบบไทม์ไลน์ อัปเดตอัตโนมัติ
- เช็กอินด้วยรหัสจอง ชื่อ เบอร์โทร หรือ HN (เตือนเมื่อมาเร็ว/สายเกินกำหนด)
- รับ walk-in / จองแทนทางโทรศัพท์ ใส่รอบที่ว่างหรือรอบที่มีคนยกเลิก/ไม่มา

**หมอนวด**
- เรียกคิว → เริ่มนวด (จับเวลา) → จบการนวด
- บันทึกจุดที่นวด / คำแนะนำหลังนวด และดูประวัติการนวดครั้งก่อน

**ระบบ**
- กันจองซ้อนระดับฐานข้อมูล (ทดสอบยิงพร้อมกัน 5 request สำเร็จเพียง 1)
- โควตา: 1 คิว/วัน และ 2 คิว/สัปดาห์ ต่อผู้รับบริการ
- ตัดสิทธิ์อัตโนมัติเมื่อสายเกิน 10 นาที (no-show) และระงับสิทธิ์การจองตามเกณฑ์ (ตั้งค่าได้)
- วันหยุด: แอดมินตั้งเอง ถ้ามีคนจองไว้แล้วระบบเตือน → ยกเลิกคิว → แจ้งให้จองใหม่ทาง LINE
- ค่าตั้งค่าเกือบทั้งหมดแก้ได้จากหน้าแอดมิน (รอบเวลา, กฎการจอง, ข้อความแจ้งเตือน ฯลฯ)
- Audit log ทุกการแก้ไข (PDPA)

## สถาปัตยกรรม

```
                    อินเทอร์เน็ต                         │            LAN โรงพยาบาล
                                                         │
 LINE OA ──► LIFF (มือถือผู้ป่วย) ──► Cloudflare Tunnel ──┼──► :4000  PUBLIC API   (หน้าจอง)
                                                         │
                         เจ้าหน้าที่ / หมอนวด / แอดมิน ───┼──► :4001  INTERNAL API (LAN เท่านั้น)
                                                         │              │
                                                         │           MySQL 8
```

- Backend แยก **2 พอร์ต**: API ของแอดมิน/เจ้าหน้าที่ไม่มีอยู่บนพอร์ตสาธารณะเลย
- ออกอินเทอร์เน็ตผ่าน **Cloudflare Tunnel** — ไม่ต้องเปิดพอร์ตบนไฟร์วอลล์ และไม่เปิดเผย public IP ของโรงพยาบาล
- โหมดการเชื่อมต่อ 3 แบบ: `LOCAL` (จำลอง LINE) · `DEV_TUNNEL` (LINE OA ทดสอบ) · `PRODUCTION`

## เริ่มต้นใช้งาน (เครื่อง dev — Windows)

**ต้องมี:** Node.js 20+ · MySQL 8.0 · Git

### 1. ฐานข้อมูล

```powershell
cd database
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p -e "source setup_dev.sql"
```

> ⚠ `setup_dev.sql` จะ **ลบแล้วสร้างฐานข้อมูลใหม่** พร้อมข้อมูลตัวอย่าง ใช้กับเครื่อง dev เท่านั้น

### 2. Backend

```powershell
cd backend
npm install
Copy-Item .env.example .env
npm run dev
```

ตรวจ: http://localhost:4001/health → `{"ok":true,...,"db":"ok"}`

### 3. Frontend (เปิดอีกหน้าต่าง)

```powershell
cd frontend
npm install
npm run dev
```

| หน้า | URL |
|---|---|
| ผู้จอง (มือถือ) | http://localhost:5173 |
| เจ้าหน้าที่ / หมอนวด / แอดมิน | http://localhost:5173/staff |

## ความปลอดภัย

- รหัสผ่านเจ้าหน้าที่เก็บแบบ bcrypt · session เป็น JWT ใน httpOnly cookie · บังคับเปลี่ยนรหัสผ่านครั้งแรก
- ฝั่งผู้จองตรวจ LINE ID token กับ LINE ทุก request
- Token ของ LINE เก็บแบบเข้ารหัส AES-256-GCM
- จำกัดจำนวน request (rate limit) · helmet · parameterized query ทุกจุด
- แอปใช้ MySQL user สิทธิ์จำกัด (ลบตารางไม่ได้)
- **ก่อนขึ้น production:** เปลี่ยน `JWT_SECRET`, `APP_SECRET_KEY` (`npm run gen-key`), รหัส DB user และ **ห้ามรัน** `04_dev_sample.sql`

> ไฟล์ `.env`, ไฟล์ backup/dump ฐานข้อมูล และ credential ของ tunnel ถูกกันไว้ใน `.gitignore` แล้ว
